Javascripts

Script Overview

The SmartHR template includes a wide range of helpful JavaScript plugins designed to enhance user experience on your SmartHR website. These plugins power features like appointment scheduling, image sliders, time pickers, and more.

You can find all the JS files organized in the js/ and plugins/ directories. Add your script inside the partials/script.html file.

<script src="assets/js/script.js"></script>

Installation

Prerequisites
Node.js Installation

Ensure that Node.js is installed and running on your system.

Download Node.js:
https://nodejs.org/en/download/
NPM

Ensure that NPM is installed and properly configured on your system. If NPM is already installed, you may skip this step.

npm install --global npm@latest
TailwindCSS

Ensure that NPM is installed and properly configured on your system. If NPM is already installed, you may skip this step.

npm install -D tailwindcss
npx tailwindcss init

How to change Logo?

You can change the logo or replace it from img folder or you can edit it from HTML file.

<div class="header">
	<a href="index.html" class="logo">
		<img src="assets/img/logo.svg" alt="logo">
	<a>
</div>
